# Phishing Website Scraper

A Python phishing-analysis project that collects website signals, builds a labelled dataset, trains a Random Forest classifier, and provides Flask and Gradio interfaces for analysing URLs.

## What I built

This project combines rule-based phishing detection with a machine-learning classifier.

The main scraper extracts signals from URLs and webpages, including:

- URL length, dots, hyphens, `@` symbols, and HTTPS usage
- raw IP addresses used as domains
- suspicious keywords
- free-hosting detection
- subdomain length and entropy
- HTML forms and password fields
- forms that submit to an external host
- domain-age information using RDAP/WHOIS
- brand matching and possible brand impersonation
- a rule-based risk score and human-readable risk reasons

The project can collect active phishing URLs from the OpenPhish feed and compares them with a built-in set of legitimate test URLs. The generated labelled data can then be used by `train_model.py`.

## Machine learning

`train_model.py` trains a `RandomForestClassifier` using the features produced by `phishing_scraper.py`.

The training script includes:

- a stratified train/test split
- 5-fold stratified cross-validation using F1 score
- a classification report and confusion matrix
- feature-importance output
- comparison against the original rule-based score
- a threshold sweep for the rule-based baseline

After training, the model is saved as:

```text
phishing_model.joblib
```

Run the scraper before training so that `labeled_dataset.csv` exists.

## Interfaces

### Flask

`app.py` loads `phishing_model.joblib`, runs the existing `analyze_url()` feature-extraction pipeline, and exposes:

```text
GET  /
POST /analyze
```

The `/analyze` endpoint returns the model prediction, phishing/legitimate probabilities, rule-based risk information, and selected extracted features.

Run:

```bash
python3 app.py
```

### Gradio

`ui.py` provides a Gradio interface around the same scraper and trained model.

Run:

```bash
python3 ui.py
```

The interface displays the model verdict, probability breakdown, rules that fired, and a signal breakdown.

## Optional GPT analysis

`gpt_phishing_analyzer.py` provides a separate OpenAI-based assessment using the structured evidence generated by the existing scraper.

It supports analysing:

- a single URL
- an existing labelled CSV dataset
- a text file containing URLs

Set your API key before using it:

```bash
export OPENAI_API_KEY="your_api_key_here"
```

You can optionally set `OPENAI_MODEL` to choose the model used by the analyzer.

Example:

```bash
python3 gpt_phishing_analyzer.py https://example.com
```

## Installation

Create and activate a virtual environment if desired, then install the dependencies:

```bash
pip install -r requirements.txt
```

Development dependencies are listed separately:

```bash
pip install -r requirements-dev.txt
```

## Typical workflow

```text
phishing_scraper.py
        |
        v
labeled_dataset.csv
        |
        v
train_model.py
        |
        v
phishing_model.joblib
        |
        +--> app.py
        |
        +--> ui.py
```

The GPT analyzer can also reuse the scraper's extracted features independently.

## Main files

| File | Purpose |
| --- | --- |
| `phishing_scraper.py` | Fetches URLs, extracts phishing signals, applies rule-based checks, and builds labelled data |
| `train_model.py` | Trains and evaluates the Random Forest classifier |
| `app.py` | Flask web server/API for URL analysis |
| `ui.py` | Gradio interface for the trained model |
| `gpt_phishing_analyzer.py` | Optional OpenAI-based analysis using scraper evidence |
| `requirements.txt` | Runtime dependencies |
| `requirements-dev.txt` | Development dependencies |

## Notes

The scraper performs network requests to URLs being analysed. Use it only in an environment where you are comfortable making those requests.

The model file and labelled dataset are generated by the project workflow; training expects `labeled_dataset.csv` to be present before `train_model.py` is run.
